# Project Brief

## Project name

ChemLoop Studio

## One-line summary

A self-auditing RAG and active-learning workbench for polymer and materials R&D.

## Problem

Researchers often move between literature review, hypothesis generation, formulation design, and experiment planning using disconnected tools. Generic AI chat tools can summarize papers, but they often fail to expose evidence quality, uncertainty, and the link between literature and concrete experimental decisions.

## Proposed solution

ChemLoop Studio connects four steps:

1. Ask a technical R&D question.
2. Retrieve relevant literature-style evidence.
3. Produce an answer with source snippets and uncertainty flags.
4. Recommend the next candidate experiment using a surrogate model.

## Why it is suitable for Burhan Beycan

The project signals broad applied AI ability while using polymer chemistry and materials science as a differentiator. It is not limited to one chemistry subtopic; the architecture can generalize to batteries, textiles, biomaterials, and other R&D domains.
