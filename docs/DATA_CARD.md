# Data Card

## Dataset name

ChemLoop Studio demonstration corpus and experiment table.

## Files

- `data/sample_papers.jsonl`
- `data/sample_experiments.csv`

## Purpose

The data are small demonstration datasets designed to make the repository runnable without external access, paid APIs, or proprietary research data.

## Intended use

- Demonstrate retrieval and evidence ranking.
- Demonstrate uncertainty flags.
- Demonstrate experiment recommendation logic.
- Support tests and examples.

## Not intended use

- Do not treat the data as a validated polymer science database.
- Do not use recommendations as real wet-lab instructions without expert review.
- Do not claim performance beyond the demonstration setting.

## Expansion plan

Future versions should add:

- Open-access paper metadata with stable identifiers.
- Explicit data provenance.
- Stronger benchmark questions.
- Experimental datasets with measured morphology, antimicrobial activity, and cytocompatibility.
