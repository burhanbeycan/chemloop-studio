# Data Card

## Dataset name

ChemLoop Studio demonstration literature corpus.

## File

- `data/literature_corpus.jsonl`

## Purpose

The corpus is a small demonstration dataset for testing literature-informed optimisation workflows. It supports retrieval, range extraction, and Streamlit demos.

## Intended use

- Portfolio demonstration.
- Unit tests.
- Local reproducibility.
- Example retrieval workflow for electrospinning and materials optimisation.

## Not intended for

- Production scientific decisions.
- Safety-critical recommendations.
- Replacing a systematic literature review.
- Replacing wet-lab validation.

## Known limitations

- Very small number of records.
- Simplified metadata.
- No DOI-level provenance.
- No quality-screening protocol.
- No experimental uncertainty model.

## Recommended next data upgrade

Curate a real open dataset with source identifiers, DOI/URL metadata, process variables, response metrics, inclusion/exclusion criteria, and a reproducible data-cleaning script.
