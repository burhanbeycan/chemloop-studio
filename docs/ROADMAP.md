# Roadmap

## Version 0.1

- Transparent TF-IDF retrieval.
- Evidence cards.
- Evidence quality score.
- Experiment recommendation with random-forest surrogate.
- CLI, API, Streamlit app, tests, and CI.

## Version 0.2

- Add benchmark questions and expected relevant documents.
- Add retrieval metrics in a report command.
- Add visualizations for experiment candidate space.
- Add optional sentence-transformer embeddings.

## Version 0.3

- Add hybrid retrieval with structured tags and vector search.
- Add LLM adapter with strict citation checking.
- Add model cards for surrogate predictors.
- Add dataset provenance templates.

## Version 1.0

- Full scientific RAG benchmark.
- Real open literature corpus.
- Active-learning loop with batched experiment recommendations.
- Deployed demo and portfolio case study.
